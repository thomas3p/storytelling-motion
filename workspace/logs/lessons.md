# บทเรียน

จดสิ่งที่เจอระหว่างทำแต่ละตอน (ปัญหา → วิธีแก้) อ่านไฟล์นี้ก่อนเริ่มเรื่องใหม่ทุกครั้ง

## 2026-10-26 · 60°C รุ่งอรุณเดือด EP1 (เครื่อง cloud)
- network policy บล็อก cdn.jsdelivr.net, freesound.org, CDN ของ Higgsfield → GSAP ใช้สำเนา npm ใน hf/assets ตอนทดสอบ, เสียงประกอบสังเคราะห์เอง, ไฟล์เสียง Higgsfield ต้องเพิ่มโดเมนหรือให้ผู้ใช้แนบไฟล์
- ไม่มี GEMINI_API_KEY และ faster-whisper โหลดโมเดลจาก huggingface ไม่ได้ → เสียงชั่วคราวเจนทีละวลี (ได้เวลาวลีตรง ๆ ไม่ต้อง ASR) แล้ว cue ในวลีประมาณจากตำแหน่งตัวอักษร
- GSAP fromTo {y: …} บน <g> ที่มี transform="translate(…)" ทับค่า translate เดิม (เครื่องแอร์ลอยขึ้นไปบนสุด) → ใส่ id ที่ <g> ชั้นใน
- Chrome ตัดบรรทัดซับภาษาไทยกลางคำ ("ก็ | คือ", "แสง | แรก"); word-break: keep-all ไม่ช่วย → build_captions รองรับ "|" ในข้อความแสดงเป็นจุดขึ้นบรรทัด
- ชื่อเรื่องต้องค้างบนจอ ≥ 1.3 วิ (check: line_unread) → เว้นจังหวะหลังวลีเปิดให้ยาวพอ
- ความดัง: เบดดนตรีที่สังเคราะห์ (≈ −18 LUFS) ต้องลด vol ~0.2–0.3 ให้อยู่ใต้เสียงพากย์ ~12 dB
