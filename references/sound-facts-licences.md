# เสียงประกอบ ข้อเท็จจริง และการจดที่มา

## เสียงประกอบ/ดนตรี (CC0)

```sh
python tools/fs_search.py search "heart monitor beep" 30 0.5      # ค้น freesound เฉพาะ CC0 (ไม่ต้องล็อกอิน)
python tools/fs_search.py get 517508 hf/assets/sfx/monitor_beep.mp3
ffmpeg -i in.mp3 -af ebur128 -f null -                              # วัดความดัง
ffmpeg -y -i in.mp3 -af loudnorm=I=-18:TP=-2 -ar 48000 out_n.mp3     # ไฟล์เบามากทำสำเนา _n
```

- เสียงสั้นที่เกือบเงียบทั้งไฟล์ ใช้ `volume=+XdB` ตาม max_volume แทน loudnorm; เสียงที่อยู่กลางไฟล์ใช้ `"ms"` ใน timeline.json
- ดนตรีหลักใส่เบา ๆ (vol ~0.2–0.3) เปลี่ยนเป็นโดรนมืดช่วงไคลแมกซ์/ปมได้
- จดทุกไฟล์ใน `assets/licences.md`: ไฟล์ · ลิงก์ freesound · CC0 · ชื่อเดิม · ใช้ทำอะไร และในตอนนั้น `hf/assets/sources.txt`

## ข้อเท็จจริง (ตอนละ 1 ข้อ)

- เลือกข้อที่ผูกกับเรื่อง (เช่น คลินิก → แนวทางความปลอดภัยการดูดไขมัน, ขยะติดเชื้อ → อุณหภูมิเตาเผาตามกฎหมาย)
- ยืนยันจากแหล่งต้นทาง: งานวิจัย/มาตรฐาน/หน่วยงานรัฐ/สมาคมวิชาชีพ ถ้าเจอแค่ข่าว ให้หาอย่างน้อย 2 แหล่งที่ตรงกันและบอกผู้ใช้ตามจริงว่าตรวจกับต้นฉบับหรือยัง
- เขียนในบทให้ตรงความหมาย (เช่น "ควร" ไม่ใช่ "ต้อง" ถ้าเป็นคำแนะนำ) ใส่บรรทัด "ที่มา: …" บนการ์ดข้อเท็จจริง
- บันทึกใน `sources.txt` และ brief: ส่วนจริง (พร้อมลิงก์) / ส่วนแต่ง / ภาพที่เป็นภาพประกอบ

## เสียงพากย์

จดใน licences: บริการ, model, voice, seed, temperature, วันที่ และตรวจเงื่อนไขการใช้งานเชิงพาณิชย์ของผู้ให้บริการก่อนลงช่องที่มีรายได้
