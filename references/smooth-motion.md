# หลักความลื่นไหล (ใช้ทุกช็อต)

คลิปต้นแบบไม่มีเฟรมค้างเลย: ภาพเปลี่ยนแค่ราว 0.2–0.7% ต่อเฟรม แต่ขยับตลอด

1. **กล้องซูมเข้าช้า ๆ ตลอด และพื้นหลังขยับต่างความเร็วกับตัวละคร (parallax)**
   `shot(dur, scale, x, y, [["#P-far", 12], ["#P-mid", -6], ["#P-near", -24]])` — ไกลเลื่อนน้อย ใกล้เลื่อนมาก
2. **ตัวละครหายใจ โยกตัว กะพริบตาตลอด และแสงไหวตลอด**
   `alive(id, r, gid, 0, dur)` (หายใจ + หัว/แขนโยก + กะพริบตาแบบสุ่มคงที่) ทุกตัวละครในช็อต,
   `flicker("#P-lamp", 0, dur, 0.8, 1, 0.4)` ไฟ/จอ/เปลวไฟทุกดวง (ใส่ scale ได้สำหรับเปลวไฟ)
3. **easing นุ่มทั้งหมด** (sine.inOut, power1/2) ห้ามขยับแบบ on twos หรือค้างนิ่งระหว่างท่า หน้าตัวละครเปลี่ยนแบบ crossfade 0.12 วิ (`face()` ทำให้แล้ว)
4. **เปลี่ยนช็อตด้วย cross-dissolve 0.3 วินาที** — `"xfade": 0.3` ใน timeline.json

ทุก repeat คำนวณจากความยาวช็อต (ไม่มี `repeat: -1`) และทุกอย่างเป็นฟังก์ชันของเวลาในไทม์ไลน์ ทำให้เรนเดอร์ซ้ำได้เหมือนเดิมทุกครั้ง
